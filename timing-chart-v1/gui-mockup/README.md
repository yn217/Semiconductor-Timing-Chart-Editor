# GUI Mockup

AI実装エージェントが画像だけでなくDOM/CSS構造を解析できる参照モックアップ。

- `index.html`: main application layout
- `styles.css`: layout/style reference
- `app.js`: Signal / Annotation / Problems / JSON bottom tabs

原画PNGはGitHub Issueのreference assetとして併記する。実装はこのHTMLの技術選定を強制されないが、領域構成・タブ・選択追従・Waveform/Inspector/Bottom Editorの関係を参照する。
