# Phase 13 Performance Report

## Measurement contract

Measurements use deterministic canonical documents generated by
`@timing-chart-v2/testing`. Supported scales are 50×100, 100×500, 500×500,
and 1000×1000; profiles cover standard, clock-heavy, bus-heavy,
annotation-heavy, transaction-heavy, and mixed documents.

The PR scenario records ten browser trials and reports median and p95. Runtime
evidence combines application counters with Chromium CDP metrics and a Long
Task observer. CI retains the JSON evidence as Playwright attachments when a
test fails; the same payload is printed in the job log on success.
Selection and pointermove are summarized independently. Repeated Open records
file-input start through the first correct visible idle state for A/B/A.

## Reference run

Reference environment: Chromium via Playwright on Windows, 2026-08-25.

| Scenario | Result |
|---|---:|
| 100×500 selection duration, median | 663.9 ms |
| 100×500 selection duration, p95 | 732.4 ms |
| pointermove duration, median / p95 | 300.6 / 319.8 ms |
| next animation frame, median / p95 | 0.4 / 0.6 ms |
| maximum observed Long Task count | 8 |
| layout count / duration delta | 34 / 0.108 s |
| style recalc count / duration delta | 49 / 0.604 s |
| 100×500 mounted / cached wave owners | 10 / 16 |
| 1000×1000 mounted rows / wave owners | 8 / 8 |
| 1000×1000 duplicate wave owners | 0 |

Durations include Playwright interaction and assertion overhead and are used
as regression evidence, not as a hardware-independent product SLA. Hard gates
are structural counter deltas and bounded mounting; percentile values remain
visible for trend comparison.

## Hard invariants

- Selection changes no render-domain counter and creates no History entry.
- Reorder preserves waveform SVG identity and adds no WaveDrom or local
  geometry build.
- One semantic signal edit adds exactly one WaveDrom render and one local
  geometry build.
- Annotation style changes and cancelled drag preview add neither waveform nor
  local geometry work.
- Horizontal scroll and zoom do not regenerate waveform artifacts or History.
- View-only scroll increments Projection builds but leaves RowLayout builds at
  zero delta.
- Annotation pointermove performs zero SnapIndex builds after the one
  gesture-start preparation.
- 1000×1000 mounts fewer than 60 rows and fewer than 60 waveform owners, with
  no duplicate signal binding.
- Repeated Open A/B/A keeps the final cache and mounted set viewport-bounded;
  one Inspector blur produces exactly one History entry.

The closure also removes four measured scaling hazards: local commits retain
structurally shared frozen branches, Dirty reads compare clean snapshot
identity, detached WaveDrom render indices are released on dispose, and the
wave owner LRU is capped at four times the mounted set (minimum 32).

## CI cadence

Pushes and pull requests run the full correctness suite plus the PR-scale
performance guard. The scheduled job runs daily at 17:23 UTC (02:23 JST) and
can also be started manually with `performance_scale=nightly`; it enables the
500×500 annotation-heavy and 1000×1000 transaction-heavy scenarios.
