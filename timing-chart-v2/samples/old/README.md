# Historical samples only

Everything in this directory is retained for migration, regression, provenance, or comparison. It is not an authoritative current product specification and must not be used to claim current feature coverage without a separate current-sample test.

`pre-reset-2026-10-02/` contains the complete active sample packs from immediately before the sample reset. Pack contents were moved intact so their local READMEs, manifests, and coverage artifacts remain beside the original JSON. `current-v2-2026-09-27/` is an earlier preserved snapshot and remains unchanged.
